# Петербург зимой · 7–12 декабря 2026

Мобильная версия сайта с планом поездки для двух человек.

## Публикация через GitHub Pages

1. Создайте на GitHub новый **Public**-репозиторий.
2. Загрузите в корень репозитория `index.html` и `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Нажмите **Save** и дождитесь завершения публикации.
6. Адрес сайта появится в этом же разделе, обычно вида:
   `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`

## Структура

- `index.html` — весь сайт: разметка, стили и JavaScript встроены в один файл.
- `.nojekyll` — отключает обработку Jekyll для GitHub Pages.

## Важно

- Сайт рассчитан на мобильные экраны и сохраняет узкую мобильную ширину даже при открытии на компьютере.
- Внешние ссылки (карты, расписания, сайты мест) требуют интернет-соединения.
- Отметки чек-листов сохраняются в браузере на конкретном устройстве.
- Для обновления сайта замените `index.html` в репозитории и выполните Commit changes.
- Сайт публичный: не размещайте в нём личные или конфиденциальные данные.
